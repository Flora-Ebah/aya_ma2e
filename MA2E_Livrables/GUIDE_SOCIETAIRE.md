## 1. Avant de commencer

### Ce que vous devez avoir sous la main

- ✅ **Votre Carte Nationale d'Identité** (CNI ivoirienne, valide). Si vous avez un autre titre (carte consulaire, carte de séjour, passeport), c'est aussi accepté.
- ✅ **Votre matricule** employeur (CIE, SODECI ou ERANOVE) — celui qui figure sur votre bulletin de salaire.
- ✅ **Un téléphone** avec WhatsApp **ou** un navigateur (Chrome, Safari, Firefox…).
- ✅ **5 minutes au calme** — pas la peine de bloquer une demi-journée, ça va vite.

### Ce qu'on va vous demander (et pourquoi)

| Information | Pourquoi MA2E en a besoin |
|-------------|---------------------------|
| Votre matricule | Vérifier que vous êtes bien employé(e) chez CIE/SODECI/ERANOVE |
| Votre CNI | Confirmer votre identité (obligation légale ARTCI) |
| Votre date de naissance | Calcul des cotisations selon votre tranche d'âge |
| Votre situation familiale | Couverture des ayants droit (conjoint, enfants) |
| Votre RIB (optionnel) | Prélèvement automatique de votre cotisation |

**MA2E ne demande JAMAIS** : votre mot de passe employeur, votre code bancaire, votre code OTP par téléphone. Si on vous le demande, ce n'est PAS MA2E.

### Vos droits — résumé en 4 points

1. **Vous pouvez refuser** la collecte de vos données. Mais sans cela, l'inscription n'est pas possible (c'est une obligation légale ARTCI).
2. **Vous pouvez retirer votre consentement** à tout moment en tapant `RETIRER CONSENTEMENT` sur WhatsApp ou dans le chat web.
3. **Vous pouvez demander une copie** de toutes vos données en tapant `MES DONNÉES`.
4. **Vous pouvez demander la suppression** de votre dossier en tapant `SUPPRIMER MON DOSSIER`. Le DPO MA2E vous répond sous 30 jours.

Conformité : loi ivoirienne **2013-450 (ARTCI)** sur la protection des données personnelles.

## 2. Parcours WhatsApp (recommandé — 5 min)

### Étape 1 — Démarrer la conversation

Envoyez le message **« Bonjour »** au **+225 87 13 75 12** sur WhatsApp.

L'assistante MA2E vous répond en quelques secondes et vous propose un menu :

```
👋 Bonjour, je suis votre assistante MA2E.

Je peux vous aider à :
1) M'identifier (nouvel enrôlement)
2) Mettre à jour mon dossier
3) Vérifier le statut de mon dossier
4) Poser une question sur MA2E
```

Tapez **1** pour démarrer votre inscription. Vous pouvez aussi écrire en langage naturel : *« je veux m'inscrire »* fonctionne aussi.

### Étape 2 — Consentement ARTCI

L'assistante affiche une notice de protection des données. Lisez-la (c'est court) puis tapez **OUI** pour donner votre consentement.

### Étape 3 — Votre employeur et votre matricule

L'assistante demande votre société employeuse :

```
Pour qui travaillez-vous ?
1) CIE - Compagnie Ivoirienne d'Électricité
2) SODECI - Société de Distribution d'Eau de Côte d'Ivoire
3) ERANOVE - Groupe ERANOVE (siège)
```

Tapez le numéro correspondant.
Puis saisissez votre **matricule** (tel qu'il figure sur votre bulletin de salaire) :

```
Saisissez votre matricule employeur :
```

Exemple : `CIE-00042`, `SODECI-09812`, `ERANOVE-00500`.

### Étape 4 — Photo de votre CNI

L'assistante vous demande la photo **recto** de votre CNI :

```
Envoyez la photo recto de votre CNI.

📷 Conseils :
• Posez la pièce sur une surface plane
• Bon éclairage
• La pièce doit être entièrement visible
• Évitez les reflets
```

Prenez la photo dans WhatsApp et envoyez-la. L'assistante demande ensuite la **photo verso** (le côté avec la bande blanche en bas).

### Étape 5 — Vérification de vos informations

L'assistante lit automatiquement votre CNI et vous montre ce qu'elle a extrait :

```
Voici les données que j'ai extraites de votre CNI :

• Nom : KOUASSI
• Prénoms : Awa Marie
• Né(e) le : 12/03/1990
• Numéro CNI : CI9876543

Ces informations sont-elles correctes ?
→ Répondez OUI pour confirmer
→ Répondez NON pour corriger
```

Si tout est bon, tapez **OUI**. Sinon, tapez **NON** et l'assistante vous demande quelle ligne corriger (exemple : *« le prénom est mal écrit, c'est Awa-Marie avec un tiret »*).

### Étape 6 — Quelques questions complémentaires

L'assistante pose 2-3 questions rapides :

- Votre fonction (technicien, comptable, ingénieur…)
- Votre ancienneté dans l'entreprise
- Votre situation familiale + nombre d'ayants droit

Vous pouvez répondre par écrit en langage normal. *« Je suis marié avec 2 enfants »* est compris.

### Étape 7 — Confirmation finale

L'assistante affiche un récapitulatif. Vérifiez, tapez **VALIDER** pour soumettre.

Vous recevez un message de confirmation :

```
✅ Votre dossier MA2E DOS-2026-00042 a bien été enregistré.

Un agent MA2E va l'examiner. Vous serez notifié(e) ici dès qu'une décision sera prise (généralement sous 48h ouvrées).

Merci pour votre confiance 🤝
```

C'est fini de votre côté. **Conservez le numéro de dossier** (DOS-2026-…). Il vous servira si vous avez besoin de joindre le support.

## 3. Parcours Site Web (alternative — 5 min)

Si vous préférez utiliser un navigateur (par exemple sur ordinateur) :

1. Allez sur **[https://app.ma2e.ci](https://app.ma2e.ci)** ou **scannez le QR code** affiché dans votre agence MA2E.
2. Une page d'accueil vous propose : `Démarrer sur WhatsApp` ou `Continuer sur le web`. Cliquez sur **« Continuer sur le web »**.
3. Le parcours est **identique** à celui de WhatsApp — les mêmes étapes (consentement → matricule → CNI → confirmation), mais dans une interface web.

**Astuce** : vous pouvez démarrer sur le web depuis votre ordinateur de bureau, puis finir sur WhatsApp depuis votre téléphone (pour photographier votre CNI plus facilement). Votre progression est conservée tant que vous gardez votre identifiant de session.

## 4. Et après ? Suivre l'avancement de votre dossier

### Vérifier le statut

Sur WhatsApp ou le web, tapez **« statut »** ou **« où en est mon dossier »**. L'assistante vous répond :

| Statut | Ce que ça veut dire |
|--------|---------------------|
| **En cours** | Vous n'avez pas encore terminé toutes les étapes |
| **Soumis** | Votre dossier est complet et attend examen |
| **En validation** | Un gestionnaire MA2E l'examine actuellement |
| **Validé** | 🎉 Vous êtes officiellement sociétaire MA2E ! |
| **Complément requis** | MA2E a besoin d'un élément supplémentaire (qui vous a été précisé) |
| **Refusé** | Votre dossier n'a pas pu être validé (le motif vous a été communiqué) |

### Recevoir une notification

Dès qu'une décision est prise sur votre dossier, vous recevez automatiquement un message **sur le même canal** que celui que vous avez utilisé (WhatsApp ou web).

Délai habituel : **24 à 72 heures ouvrées** après soumission.

### Mettre à jour vos informations

Si vous changez de fonction, de RIB ou de situation familiale, retournez sur WhatsApp ou le web et tapez **« mise à jour »**. L'assistante vous guide.

## 5. FAQ

> **Combien ça coûte ?**
>
> L'enrôlement digital est **gratuit**. Seules vos cotisations mensuelles MA2E (calculées selon votre statut) seront prélevées une fois votre dossier validé.

> **Et si je n'ai pas de smartphone ?**
>
> Vous pouvez vous rendre à votre agence MA2E habituelle, où un gestionnaire pourra saisir votre dossier pour vous (parcours back-office). Le service digital est une **option** pour aller plus vite, pas une obligation.

> **Mes données sont-elles vraiment sécurisées ?**
>
> Oui. Vos photos de CNI sont **chiffrées au repos** (chiffrement AES-256) et n'apparaissent qu'aux gestionnaires MA2E autorisés. Aucune donnée n'est partagée avec un tiers sans votre consentement explicite. MA2E est en conformité avec la loi 2013-450 (ARTCI).

> **Combien de temps mes données sont-elles conservées ?**
>
> Conformément à l'article 36 de la loi ARTCI, vos données sont conservées **5 ans** après votre dernière activité comme sociétaire. Passé ce délai, elles sont automatiquement supprimées (sauf demande de prolongation pour raisons comptables ou légales).

> **L'OCR a mal lu ma CNI. Que faire ?**
>
> Dans l'étape 5 du parcours, tapez **NON** quand l'assistante vous demande si les données sont correctes. Elle vous demandera quelle ligne corriger. Vous pouvez aussi re-prendre une photo plus nette.

> **Je n'ai pas reçu de réponse depuis 3 jours. C'est normal ?**
>
> Si plus de 72h ouvrées se sont écoulées sans nouvelle, contactez le support :
>
> - Tapez **« agent »** sur WhatsApp pour parler à un conseiller humain
> - Ou envoyez un email à **support@ma2e.ci** avec votre numéro de dossier

> **J'ai démarré sur WhatsApp mais je veux passer sur le web. C'est possible ?**
>
> Pas directement aujourd'hui (les deux canaux ont des sessions séparées). Continuez sur le canal où vous avez commencé. C'est plus simple.

> **Je veux supprimer mon dossier. Comment faire ?**
>
> Tapez **« supprimer mon dossier »** (en respectant la formulation). L'assistante vous transmet à notre Délégué à la Protection des Données (DPO), qui vous répond sous 30 jours et procède à la suppression sauf obligation légale contraire.
